# M34f checkpoint: UI polish, the final pass

Date: 2026-10-15. M34's last round, after M20. It applies the checklist (D25, [`docs/ui-guidelines.md`](../ui-guidelines.md)) to what M34d and M34e didn't walk:
- the documents that work as dialogs;
- the in-window dialog's forms;
- the surfaces of the milestones since M34e: M28's AI Chat, M20's Devices window and the device picker;
- accessible names everywhere.

No new ADR.

## Done

**Tests** (`PolishFinalPassTests`, part of `PolishTests`):
- **Documents and dialogs at their minimum size cut no text, and name every control.** It opens these documents at 640 px (a 1280×720 window with a tool window docked on each side) and checks them with M34d's clipped-text walk:
  - Options, Keyboard Shortcuts, Check Environment;
  - Project Properties, NuGet, Configuration Manager;
  - Add New Item, the Template Manager.

  It also opens the in-window dialog at 440 px in each form: a dangerous confirmation, a name with a validation error, a preview of changes, a reorderable checklist.
- **Every tool window's controls have an accessible name.** It walks every registered tool window, M20's and M28's included. A visible, enabled button, toggle, combo box, text box, slider, list or tree needs an automation name, a labeling control, its text, or a placeholder. A tooltip doesn't count. Rows are named by their item styles, so controls inside row templates are left out.

**What they found, fixed:**
- **Keyboard Shortcuts:** the fixed columns (190 + 220 + 170 px) left the Command column 16 px at 640 px, so its header was cut off. The columns are now 150, 170 and 120 px, the headers trim, and the key and source columns trim with tooltips.
- **Add New Item:** the 170 px categories and 340 px preview left the template list 34 px, cutting every template's name and detail. The columns are now `150,2*,1.5*`, and the names and details trim with tooltips.
- Every tool window and every dialog form already named its controls.

**The gallery** (`shell.gallery`) now also photographs:
- Add New Item, the Template Manager and Check Environment;
- the in-window dialog as a preview of changes, a checklist and a name with an error.

The Devices window and AI Chat were already in it (it walks every registered tool window).

**The UI guide** adds:
- the minimum sizes of documents and dialogs, and the rule for columns;
- that a tooltip isn't an accessible name.

## Results

Linux (this container): the new tests pass. `UxPassTests`, `IconColorTests`, `LocalizationCatalogTests` and the M34d tests pass too.

## Open: the maintainer's part (D25)

M34's exit criteria are the maintainer's approval of the gallery on three OSes, and the check at display scales from 100 % to 200 %. Both are decisions or need real displays, so M34 stays at its checkpoints until then:
- **The gallery from a smoke run on each OS.** CI's `smoke` job uploads it with its artifact, and `eng/smoke-test.sh` writes it locally.
- **Display scales:** the headless tests lay out in device-independent pixels, so 150 % and 200 % need a look on real displays (Windows' scaling, a Retina Mac, Linux with `GDK_SCALE`/`QT_SCALE_FACTOR`).
