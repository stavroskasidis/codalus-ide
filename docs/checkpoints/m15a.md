# M15a checkpoint: the ASP.NET Core loop

Date: 2026-10-10. Decision: [ADR 0022](../adr/0022-aspnet-core-loop.md). M15b (Hot Reload through `dotnet watch`) and M15c (scaffolding, service references) follow.

## Built

**Language host:** `daedalus/aspnet/endpoints` (`AspNetEndpointsFeature`). It scans only projects that reference ASP.NET Core:
- **Minimal APIs:** `Map*` calls, checked semantically, with `MapGroup` prefixes followed through chained calls, locals and fields, and the verbs of `MapMethods`.
- **Controllers:** attribute routes with `[controller]` and `[action]` replaced, absolute templates, and conventional routes for actions without attributes.
- **Handlers** are located: a method group goes to its method, a lambda to itself.

**Workbench**
- `HttpFileParser`: requests, names, variables, query lines, headers and bodies.
- `HttpVariables`: file, environment and request variables (JSONPath and headers of named responses), dynamic variables.
- `HttpEnvironments`: `http-client.env.json` with `$shared` and the `.user` override.
- `HttpService`: sends with `HttpClient`, accepts untrusted localhost certificates, keeps a history.
- `WebDevelopmentService`: `dotnet dev-certs https` check and trust, `dotnet user-secrets init`, and the `secrets.json` path.
- `RunService.EnvironmentOverride`: the ASP.NET Core environment for every run and debug session.

**Shell** (`ShellHost.Web.cs`, `WebViewModels.cs`)
- **Endpoints Explorer** (View menu):
  - endpoints by project, with search;
  - opens a handler;
  - **Generate Request** appends to `<Project>.http`, with a host variable from the launch profile, route parameters as `{{variables}}`, and a JSON body for POST, PUT and PATCH;
  - refreshes after the language service is ready and after C# files are saved.
- **`.http` files:**
  - the `http` language with our TextMate grammar (`grammars/http.tmLanguage.json`, shipped next to the shell);
  - send glyphs in the margin, `Ctrl+Alt+R`, and the editor's context menu;
  - choosing an environment.
- **HTTP Response window:** the status, time and size; the body colored and formatted by content type; the headers; the request as sent; the history.
- **Debug menu:**
  - Select the ASP.NET Core Environment (saved with the solution);
  - Check and Trust the HTTPS Development Certificate, with Linux guidance;
  - before the first run or debug session of a profile with an https URL, an offer to trust the certificate.
- **Project → Manage User Secrets** (also on a project's context menu). `secrets.json` uses the `appsettings.json` schema in the markup host.

**Fixture:** `samples/Web`:
- minimal APIs (a group, a method group, `MapMethods`);
- an API controller with attribute routes;
- a launch profile, `appsettings.json` and `WebApi.http`.

**Tests**
- **Language host:** `AspNetEndpointsTests`: the ten endpoints of the fixture with their handler locations, and filtering by project.
- **Workbench:**
  - `HttpFileTests`: parsing, variables, environments, and requests to a local `HttpListener` with request variables chained between them;
  - `WebDevelopmentTests`: `user-secrets init`, and the environment override.
- **Headless UI:** `WebTests` on the running fixture app: the Endpoints Explorer, the `.http` grammar and glyphs, two requests and the formatted JSON response, Generate Request, the environment override.
- **Smoke test:** step `web.http` (M15): the Endpoints Explorer, then a `.http` request to the running app.

**Docs:** ADR 0022, [User guide: Web development](../user-guide/web.md), the protocol (`daedalus/aspnet/endpoints`), the shortcut table and the roadmap (M15 split into M15a, M15b and M15c).

## Found during validation

- **The Reference Manager could show stale references.** It waited for the project's next evaluation only after the edit returned. An evaluation that arrived first, or one already under way, ended the wait early, and the window reloaded once with the old references. Now every evaluation of the project reloads it for two minutes after an edit.
- **Peek Definition** can briefly find nothing while design-time builds reload the projects. The M12a test now asks again, as the smoke test does for completion. While investigating, no RPC request was stuck.

## Not done, and deviations

- **Send glyphs** in the margin instead of a "Send request" CodeLens: our CodeLens comes from language servers, and `.http` has none.
- **The Endpoints Explorer doesn't list:** routes built at run time, Razor Pages, and endpoints added by libraries.
- **`appsettings.json` keys from options classes** aren't discovered; the bundled schema is unchanged. `TODO(issue)`.
- **The `.http` runner** has no proxy, client-certificate or timeout settings, and no "Debug" next to "Send". `TODO(issue)`.
- **Budget:** "Endpoints Explorer populated ≤ 1 s after the solution loads" isn't measured yet. `TODO(issue)`.
