# M34e checkpoint: UI polish, round 3

Date: 2026-10-13. This round covers M34d's open items and the Mac's review of the tabs. No new ADR: the choices follow ADR 0019 (look and feel) and [`docs/ui-guidelines.md`](../ui-guidelines.md).

## What changed

**Document tabs.**
- **Tabs fit their group** (`Controls/DocumentTabPanel`). They keep their natural widths. When they don't fit, whole tabs leave from the right, but never a pinned or the selected one.
  - Dock's strip scrolled sideways, which took pinned tabs out of view (the Mac's review).
  - Dock's template takes the panel from the resource `DockDocumentTabStripHorizontalItemsPanel`, which `ShellStyles.axaml` overrides.
  - Its own `ScrollViewer` sets `HorizontalScrollBarVisibility="Auto"`, which a style can't reach, so the panel turns it off when attached.
  - Hidden tabs are arranged past the clipped edge, because a zero-size arrange would still give them their minimum width.
- **Window → Open Documents…** (`workbench.showOpenDocuments`): every open document in the quick pick, with pinned and preview ones marked. It reaches the tabs that don't fit.
- **The tab's context menu is ours**: the menu location `documentTab/context`, which plugins can add to.
  - Close, Close All But This, Close All to the Right, Close All But Pinned, Close All Documents.
  - Pin or Unpin Tab, Keep Open.
  - Copy Full Path, Open Containing Folder (Reveal in Finder).
  - Split Right and Down.
  - Right-clicking a tab makes it the active document first; Dock's menu (Float, Close…) no longer opens.
- **The preview tab keeps its color** whenever it's selected, not only while its group has the focus (the Mac's review: it didn't stand out).

**Toolbars.**
- Items in a toolbar's overflow menu aren't Tab stops; they become stops again once they show (M34d's open item).
- The tool windows that still wrapped their toolbars use `ToolbarPanel`: the .NET Counters, .NET Tools and Entity Framework migrations windows. So does a plugin tree view's title commands (the Start page's Refresh and Toggle Start Page on Startup).

**The Error List** names the project of a file its project doesn't list: the deepest project folder that holds it (M34d's review, a test project's files).

**Tests.**
- `PolishTests`:
  - document tabs that don't fit leave from the right, keeping pinned and selected ones;
  - 16 documents in 1000 px keep the pinned and selected tabs in view, unscrolled and uncut;
  - the tab menu's commands, and that right-clicking a tab activates it;
  - hidden toolbar items aren't Tab stops.
- `CompoundDebugTests` skip without netcoredbg like the other debugger tests. In a worktree they waited out 600 s, which looked like a hang.
- The design-time cache test checks only the cold open's first builds; the macOS runner's restore rebuilt one project from a cache the same session had written.
