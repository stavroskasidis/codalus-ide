# M28c checkpoint: AI agent mode and MCP

Date: 2026-10-15. The last part of M28 (D7). Agent mode follows the roadmap's rule: every file change goes through the preview, every command through an approval, and it is bounded by workspace trust. MCP works both ways: the user's MCP servers give agent mode tools, and `codalus mcp` gives other agents the IDE's context. ADR 0063 is the safety model. With this part, M28 is done.

## Done

**Agent mode** (AI Chat's Agent switch; `AiChat.SendAgentAsync`, `AgentTools` in workbench `Ai/Agent/`, `ShellHost.Agent.cs`):
- **The loop**: the model calls tools through the chat API (the provider API has carried tools since M28a), and the workbench runs them and sends the results back until the model answers without one.
  - At most `ai.agent.maxSteps` (25) calls. At the limit the model gets one more turn, without tools, to summarize.
  - Stop cancels the request and the running tool.
  - Each call is a step of the turn (`⚙ tool target → outcome`) and a line of the request log, without content.
  - The exchange joins the conversation's history, so a follow-up question knows what happened.
- **Reading tools** run without asking: `read_file` (numbered lines), `list_files`, `search_text` (a regular expression, an optional name glob, 100 matches), `get_diagnostics`, `get_build_output` and `build`.
  - Paths resolve inside the workspace only, and a link that leads out is refused.
  - Excluded files (ADR 0062) are reported as excluded, never read.
  - Every result is redacted and cut at 20,000 characters.
- **Changes**: `edit_file` (an exact text that must occur once; CRLF files handled) and `create_file`. Each shows in the refactoring preview: Apply changes the editor (unsaved, in undo), and Cancel rejects it. The model is told the change was rejected and not to try it again.
- **Commands**: `run_command` asks with the command line and its folder, and Reject is the default, so Enter refuses. Allowed commands run through `cmd /c` or `/bin/sh -c` with captured output, for at most `ai.agent.commandTimeoutSeconds` (120). The output is redacted.
- **When it can run**: a trusted solution or folder, and a model that takes tools (named when it doesn't).
- **Untrusted text**: the system prompt says what the model reads is data, never instructions. The approvals don't depend on it.

**MCP client** (`McpClient`, `McpServers` in workbench `Ai/Mcp/`):
- **Configuration**: `ai.mcp.servers` is read from user settings only, so a cloned repository can't add a process or a tool.
- **The protocol**: MCP over stdio, as newline-delimited JSON-RPC 2.0 written by hand (Native AOT clean): `initialize`, `notifications/initialized`, `tools/list` with pagination, `tools/call`, and answers to the server's `ping`.
- **Servers**: they start the first time agent mode needs their tools, restart when the setting changes, and stop with the IDE. A failing server is logged and left out.
- **Tools** are offered as `<server>__<tool>`. Each call asks first with the arguments, and its text result is redacted.

**MCP server** (`codalus mcp`; `McpStdioServer`, `McpBridge`):
- **`codalus mcp`** (Program.cs, before any window) serves MCP on stdio. It relays each call over a pipe of the current user, `<instance pipe>-mcp`, to the running IDE of the same user-data folder.
- **The IDE's side**: it listens only while `ai.mcpServer.enabled` is on (user settings, off by default).
- **Tools**: `get_solution`, `get_open_files` (with the active selection), `get_diagnostics`, `get_build_output`, and `build`, which asks in the IDE first.
- **What comes back**: excluded files are left out, text is redacted, and each call is logged.
- **Without the IDE, or with the setting off**: every call answers with what to do.

**Docs**: ADR 0063, the user guide's AI page (agent mode, MCP servers, Codalus as an MCP server, settings), `codalus --help`, `CLAUDE.md`, and the Features page.

**Tests**:
- **`AgentToolsTests`** (6):
  - reading confined to the workspace (`..`, absolute paths, a link out), excluded and ignored files, redaction, listing and search;
  - edits and creation through the stand-in preview, ambiguous and missing text, rejection;
  - commands and an MCP tool refused and allowed, with the command's output;
  - `ai.mcp.servers` parsing and safe tool names;
  - the bridge's round trip and its error without the IDE;
  - the stdio server's initialize, tools, calls, errors and unknown methods.
- **`LanguageModelPluginHostTests`**, through the real plugin host: an agent turn with a `read_file` step, the tool result sent back, the tools offered, and the log without content; and the step limit.
- **`AgentShellTests`** (2):
  - In BuildAndRun, the agent's edit shows in the preview and Apply changes `Greeter.cs`. Its `dotnet test` asks first, and Enter refuses it.
  - `dotnet codalus.dll mcp` started as an MCP server by `McpClient`: its tools are listed, a call is refused while the setting is off, and calls reach the IDE once it's on.

## Results

Linux (this container): the solution builds without warnings. The new tests pass, as do the catalogue, menu, icon and accessibility checks. The full runs:

| Project | Passed | Failed | Skipped |
|---|---|---|---|
| Shell | 269 | 1 | 10 |
| Plugins | 152 | 0 | 0 |
| Workbench | 454 | 3 | 10 |

- **Shell:** the failure is `Net11Tests`' Hot Reload test, which timed out while a workload was being installed into the .NET 11 SDK at the same time. Run again on its own, all three `Net11Tests` pass.
- **Workbench:** two failures come from the container, as before: `DevContainerTests` (no Podman) and `DiagnosticsHostTests` (a `/proc/2/environ` race while listing processes).
- **Workbench, a real bug the full run found:** `AgentToolsTests` showed that `list_files` followed a link out of the workspace and listed what was behind it. Now links are listed and never followed, and `search_text` skips them. The test checks this. It passes, and so does the class.
- **Skipped:** no container engine and no Chromium browser.

**Needs validating on Windows and on the Mac** (the Mac session had no usage left on 2026-10-15):

- `codalus mcp` from the Native AOT build with a real agent;
