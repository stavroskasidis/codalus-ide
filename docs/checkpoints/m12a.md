# M12a checkpoint: navigation and inline information

Date: 2026-10-10. Decision: [ADR 0017](../adr/0017-navigation-and-inline-information.md) (navigation depth and inline information). M12b (editing, refactoring UI and analysis) follows.

## Built

**Language host (C#)**
- `textDocument/documentSymbol` from syntax: nested namespaces, types and members, with signatures.
- **Call hierarchy** (incoming with call sites, outgoing) and **type hierarchy** (supertypes, subtypes). Items carry the symbol's documentation id, so framework symbols can be listed and expanded.
- **Inlay hints:**
  - parameter names before literal, `null`, `default` and `new` arguments;
  - types after `var`, `foreach` variables and deconstructions, and before untyped lambda parameters;
  - Visual Studio's suppression rules.
- **CodeLens:** lenses from syntax; `resolve` counts references and implementations.
- `daedalus/references`: references classified as declaration, read, write or name-only, with the containing member, project and line text.
- `daedalus/base`: Go to Base.
- `daedalus/inheritanceMargin`: relations for a range.
- `daedalus/symbolInfo`: F1 help links (learn.microsoft.com for framework symbols, the package's `projectUrl` otherwise).
- **Metadata navigation:**
  - the original source from the assembly's portable PDB (embedded, or a `.pdb` next to it);
  - Source Link downloads, cached, when `navigation.sourceLink` is on (off by default);
  - otherwise decompiled C#, as before.

**Bridge (ADR 0016)**
- The normalizer nests flat `SymbolInformation[]` and joins inlay hint label parts.
- Plugin language servers get the outline, navigation bar, sticky scroll, hierarchies, inlay hints and CodeLens through the standard requests.

**Editor**
- Inlay hints are zero-length elements: Left and Right skip them.
- CodeLens at the end of declaration lines; clicking a count runs Find All References or Go to Implementation.
- Inheritance margin glyphs with a menu of targets.
- Indentation guides and bracket pair colors (C-style lexing, cached per line).
- Inline diagnostics (optional).
- **Navigation bar:** type and member drop-downs that follow the caret.
- **Sticky scroll:** from document symbols, or foldings for other languages.
- **Overview ruler:** errors, warnings, Git changes, breakpoints, find results and the caret, with a health square that goes to the next problem.
- Requests are debounced and limited to the viewport. A failed request is retried with backoff, and hints are re-requested when diagnostics arrive.

**Commands**
- Peek Definition (`Alt+F12`): a read-only, highlighted popup.
- Go to Base (`Alt+Home`) and Go to Derived Types.
- Call Hierarchy (`Shift+Alt+H`) and Type Hierarchy.
- Help on Symbol (`Shift+F1`).
- Next and Previous Problem (`F8`/`Shift+F8`).
- Go to Last Edit Location (`Ctrl+Shift+Backspace`).
- The editor context menu has navigation and refactoring entries.

**Tool windows**
- Document Outline, with a filter, following the caret.
- Hierarchy: lazy, recursive.
- Code Definition: follows the caret.

**Find All References**
- Each reference is marked read, write or declaration, with its containing member.
- Results group by file, project or none, and filter by kind.
- The last ten result sets are kept.

**Settings** (all under Text Editor unless noted)
- `editor.inlayHints.parameterNames`, `editor.inlayHints.types`;
- `editor.codeLens`, `editor.inlineDiagnostics`, `editor.inheritanceMargin`;
- `editor.guides.indentation`, `editor.bracketPairColorization`;
- `editor.stickyScroll`, `editor.overviewRuler`, `editor.navigationBar`;
- `navigation.sourceLink` (Navigation).

## Measurements (Windows, Native AOT, `self-driven`, 100k-line C# file)

| Configuration | Typing p50 | Typing p99 | Scroll frame p99 | Private memory (process tree) |
|---|---|---|---|---|
| M11 (2026-10-09, 23:51) | 9.2 | 23.1 | 17.6 | 699 MB (1 run) |
| M12a, inline information on (2 sessions, 4 runs) | 10.0–10.2 | 28.0–29.4 | 17.4 | 813–950 MB |
| M12a, all inline information off (2 sessions, 4 runs) | 9.2–9.4 | 23.0–34.1 | 17.3 | 770–875 MB |

- **Typing:** the inline features cost under 1 ms at the median. The p99 spread between identical runs (23–34 ms) is larger than the difference between on and off.
- **Machine:** the same 0.5 s composition stalls as at M10 appeared in every run (scroll max 485–552 ms; one 704 ms keystroke in one run). Budget 2b (p99 ≤ 16 ms) wasn't met on this machine before M12a either.
- **Memory** varies by 100–180 MB between identical runs (the hosts' GC timing). The configurations overlap, so no M12a cost could be separated from the noise.
- `TODO(issue)`: re-measure on a quiet machine.
- **New:** `DAEDALUS_BENCH_SETTINGS` gives the shell user settings in harness runs, to compare configurations.

## Not done, and deviations

- **CodeLens placement:** at the end of the line, not above it (ADR 0017; AvaloniaEdit has no variable line heights). `TODO(issue)`: a line-above presentation.
- **Sticky scroll** lives in the adorner layer. The editor draws its text above its own layers and above sibling controls, which the headless UI test's screenshots showed.
- `TODO(issue)`, not in M12a:
  - **Solution Explorer:** members under files; generated sources under each analyzer.
  - **Browsers:** Class View and the Object Browser.
  - **Symbol servers:** the Microsoft and NuGet symbol servers.
  - **CodeLens:** Git authors and test status.
  - **Indexing:** Go To All's persistent index.
- **Found during validation, fixed:**
  - **Linux:** a plugin terminal test timed out under load. Text sent right after creating a terminal could be dropped by a shell that wasn't ready. `terminal/sendText` now waits (up to 5 s) for the shell's first output.
  - **Inlay hints:** could stay empty when the first request raced the project load. They are re-requested when diagnostics arrive, and failed requests are retried.
- **Native AOT warnings (`IL2026`/`IL3050`) in `SolutionExplorerView` and `SdkView`.** Compiled XAML templates there bind through reflection: 4 and 6 bindings. They predate M12a (M2 and M9b), and earlier checkpoints missed them because only the tail of the publish output was read. `TODO(issue)`: make those bindings compiled. Dock's own 3 warnings are known.
