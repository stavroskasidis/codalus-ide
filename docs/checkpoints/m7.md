# M7 checkpoint: hardening and release (MVP)

Date: 2026-10-09. Decisions: [ADR 0009](../adr/0009-packaging-and-release.md). This completes the original milestone plan (M0–M7): Daedalus Studio is at its MVP.

## Built
- **Packages** (`eng/package.sh <version>`):
  - **Windows**: a portable zip with winget manifests (version, installer and locale; dependencies on the .NET SDK and git).
  - **macOS**: a `.app` with a generated `Info.plist` and `.icns`, in a `.dmg`, signed when `DAEDALUS_CODESIGN_IDENTITY` is set (hardened runtime).
  - **Linux**: a `.tar.gz`, a `.deb` (`/opt`, `/usr/bin/daedalus`, a desktop entry and an icon), an AppImage (pinned appimagetool and runtime, added after the checkpoint), and a Flatpak manifest.
  - Every package bundles netcoredbg (pinned and checksummed) and the license files.
  - `release.yml` builds all three on manual dispatch.
  - Verified locally on Windows: the zip extracts with portable paths, `daedalus --version` prints the stamped version, and the packaged app starts with its hosts, plugins and the Git menu (screenshot checked).
- **Performance gates**: `benchmarks.yml` (the `compare` regression gate, ADR 0002) runs on every push once the repository is public, and stays manual while it is private. `ci.yml` switches to the full 3-OS matrix on pushes and pull requests once the repository is public. No workflow edits are needed when it flips.
- **Crash reporting**, local and opt-in:
  - The setting **Privacy → Save Crash Reports** is off by default.
  - Reports are text files in the logs folder: version, OS, runtime, exception and log tail. Crashes, recovered UI errors and helper-host crashes all produce one.
  - The next start notifies once; Help → Open Crash Reports Folder shows them. Nothing is uploaded.
- **Accessibility pass** ([docs/accessibility.md](../accessibility.md)): keyboard paths, automation names and color independence checked. Diffs gained `+`/`−` sign margins. The gaps found are listed below.
- **User documentation** ([docs/user-guide](../user-guide/README.md)): installing, solutions, editing, build and run, debugging, Git, settings and shortcuts, troubleshooting, logs and crash reports.
- **Going public** ([docs/release/go-public-checklist.md](../release/go-public-checklist.md)):
  - **History audit**: no secrets, a single author identity, no AI trailers, no local paths, no large or proprietary binaries.
  - **Community files**: `SECURITY.md` (private vulnerability reporting), `CODE_OF_CONDUCT.md` (Contributor Covenant 2.1, adopted by reference), an updated `CONTRIBUTING.md` (pull-request workflow, DCO), and issue and pull-request templates.
  - **Branch protection settings** to apply, and decisions for the maintainer on the project brief (since deleted), `CLAUDE.md` and the uncommitted `docs/roadmap.md`.
  - **NuGet prefix**: `Daedalus.*` is taken on nuget.org by unrelated packages, so the request is drafted for **`DaedalusStudio.*`** ([nuget-prefix-reservation.md](../release/nuget-prefix-reservation.md)).
  - **Name conflicts to check** ([name-conflicts.md](../release/name-conflicts.md)): the Cardano wallet "Daedalus" (IOG), US filings for DEDALUS (developer tools, 2025) and DAEDALUS (software development services, 2024), and others.
- **Fixes from the M6 CI run**:
  - `GitService` canonicalizes the paths it receives.
  - The RPC read loop tolerates a completed pipe at disposal.
  - Status-bar assertions wait for posted updates.
  - The completion test re-triggers on a cold, empty first response.
