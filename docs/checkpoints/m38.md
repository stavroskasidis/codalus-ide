# M38 checkpoint: the start window

Date: 2026-10-13. The maintainer asked for it the same day, after the classic IDE's "What would you like to do?" window. No ADR: a new window on existing services.

## Done

**The start window** (`StartWindow`, `StartWindowViewModel`, `ShellHost.StartWindow.cs`):
- **When it opens**: when the IDE starts with nothing to open (no path, remote, diff, merge, wait file, smoke test, benchmark or screenshot), and from File → Start Window. It's a window of its own, owned by the main window and centered on it.
- **The list**: recent solutions, projects and folders under Pinned, Today, Yesterday, This week (from Monday), This month and Older. Each entry shows its file icon, name, folder and when it was last opened, in the user's format. A pin button shows on hover, on the selection, and always on pinned entries.
- **Each entry's menu**: Open, Open in New Window, Pin or Unpin, Copy Path, Remove from List.
- **A missing entry**: says so, and opening it offers to remove it.
- **Keys**: `Alt+S` searches by name or path. `Down` goes from the search box to the list, `Enter` opens the selection (or the first match from the search box), `Delete` removes it, and `Esc` continues without code.
- **On the right**: Create a new project (the Templates plugin's New Project), Open a project or solution, Open a folder and Clone a repository, each with its command's icon and a line about it. Below them, Continue without code.
- **Environment → On Startup** (`workbench.startup`): the start window (default), an empty window, or the last solution.

**Recent entries** (`RecentSolutions`):
- **What's kept**: entries now carry their last-opened time and a pin. Pinned entries stay; the others keep the newest 50 (it was 15).
- **Older files**: a file written before M38 (paths only) reads as the same list, with its times unknown, so it lands under Older.
- **Grouping**: `RecentSolutions.Group` does it for a given clock, so tests fix the date.
- **Unchanged**: File → Open Recent and the Start page's list read the same entries.

**Translations**: the window's text is in the catalogue (`startWindow.*`), and its messages and group names are `msg.startWindow.*`.

**Tests**:
- `ModelTests.Recent_entries_keep_their_times_and_pins_group_by_date_and_read_the_older_file`: groups on a fixed Wednesday, pins surviving the cap, and the older file.
- `StartWindowTests`: the window lists a solution and a missing entry, search, pin, remove, opening a solution closes it, and Continue without code.
- The smoke step `shell.startWindow` (M38) opens it in the shipped app and saves `start-window.png` for the website.

## Results

Windows: the recent-entries and start-window tests, the catalogue, the menu and the icon checks passed. Landed on `develop` at `7a400b7` (2026-10-13). The 3-OS run is CI's parallel run on that commit; its `shell.startWindow` smoke step saves the website's screenshot.
