# M12b checkpoint: editing, refactoring UI and analysis

Date: 2026-10-10. Decision: [ADR 0018](../adr/0018-editing-refactoring-ui-and-analysis.md) (editing, refactoring UI and analysis). With M12a ([checkpoint](m12a.md)) this completes M12. Next: M29 (Visual Studio look and feel), then M13.

## Built

**Snippets**
- `SnippetRegistry` (workbench): VS Code's JSON format, sources in order built in, plugins, user; the user's win by name.
- Built-in C# snippets (35, Visual Studio's names: `prop`, `propfull`, `ctor`, `class`, `for`, `foreach`, `if`, `try`, `using`, `region`, `cw`, `svm`, `fact`…).
- Expansion through AvaloniaEdit's snippet engine: linked placeholders, `$0`, choices (first value), variables (`TM_SELECTED_TEXT`, `TM_FILENAME_BASE`, `CLIPBOARD`, dates…).
- Insert Snippet (`Ctrl+K Ctrl+X`), Surround With (`Ctrl+K Ctrl+Shift+S`), snippets in completion by prefix.
- Configure User Snippets and Import Visual Studio Snippets (`.snippet` XML).
- **Plugin API 0.2.5:** `contributes.snippets`; snippet-only plugins are declarative. Language servers' snippet completions (`insertTextFormat: 2`) expand too.

**Editing**
- Duplicate line (`Ctrl+D`), Move Line Up/Down (`Alt+Up/Down`).
- Expand and Shrink Selection (`Shift+Alt+=`/`-`) over `textDocument/selectionRange`.
- `///` above a member completes the documentation comment (`daedalus/docCommentTemplate`).
- Clipboard ring (`Ctrl+Shift+V`, the last 15 copies), Paste JSON as Classes.
- Per-editor zoom (`Ctrl+Shift+.`/`,`, `Ctrl+Wheel`).
- Format on save (`editor.formatOnSave`).

**Code Cleanup and analysis configuration**
- `daedalus/codeCleanup`: Fix All per configured id (default profile: IDE0005, IDE0001, IDE0002, IDE0011, IDE0040, IDE0044, IDE0090, IDE0161), then sort usings and format. `Ctrl+K Ctrl+E`, or on save (`codeCleanup.onSave`).
- Light bulb: Suppress with `#pragma`, and Configure severity (writes `dotnet_diagnostic.<id>.severity` to the nearest `.editorconfig`, creating one next to the project).

**Refactorings with options** (`daedalus/codeActionOptions`)
- Generate constructor…, Generate Equals and GetHashCode…, Generate overrides…, Extract interface…, Change signature….
- One generic dialog: an optional name and a checklist, reorderable for Change Signature. The answers go into the action's `data.choices` for `codeAction/resolve`.

**Safety**
- AutoRecover: modified documents backed up every 30 s to `<state>/backups`, offered for restore after a crash (`files.autoRecover`), deleted on a clean exit.
- Local history: the previous version on each save (`<state>/history`, 50 per file, up to 2 MB). Show Local History opens a diff and offers to restore.

**Bookmarks and the Task List**
- Bookmarks with names (`Ctrl+K Ctrl+K`, `Ctrl+K Ctrl+N`/`P`, `Ctrl+K Ctrl+L`), a margin glyph and a Bookmarks window; kept in the state folder across sessions.
- Task List: `TODO`, `HACK`, `UNDONE` (setting `taskList.tokens`) in the solution's files, unsaved text included.

**Analysis**
- **Code Metrics** (`daedalus/codeMetrics`, Analyze menu): maintainability index, cyclomatic complexity, depth of inheritance, class coupling, source and executable lines, per project, namespace, type and member. Copy as tab-separated text; double-click to go to a member.
- **Syntax Visualizer** (`daedalus/syntaxTree`): the syntax tree with tokens and trivia (structured trivia expanded), following the caret; the node's properties, its semantics and its `IOperation` tree. Selecting a node selects its text.

**Files and tabs**
- Compare Files… and Compare Active File With… (the M6 diff viewer).
- Close All to the Right.
- An image viewer for PNG, JPEG, GIF, BMP, ICO and WebP, with zoom and fit.

**Menus:** a new **Analyze** menu (Code Metrics, Code Cleanup, Syntax Visualizer), between Test and Tools as in Visual Studio.

**Tests**
- **Workbench:** snippet parsing (JSON, Visual Studio XML, TextMate syntax), bookmarks, local history.
- **Language host:** selection ranges and doc comments, suppression and severity actions, Code Cleanup, refactorings with options (Generate constructor across partial files, Extract interface into a new file, Change signature reorder and removal), the Syntax Visualizer (including doc comment trivia), Code Metrics.
- **Headless UI:** editing commands, local history, AutoRecover, format on save, JSON classes, snippets and Surround With, the dialog's checklist, the Syntax Visualizer and Code Metrics windows, the image viewer, Close All to the Right.
- **Smoke test:** step `editor.editing` (M12): Expand Selection, Duplicate Line, a snippet, the Syntax Visualizer and Code Metrics on `samples/BuildAndRun`.

## Not done, and deviations

- **Benchmarks:** not re-run for M12b. The new features add no per-keystroke work (snippets and selection ranges run on demand; the Syntax Visualizer only while open, 400 ms after the caret stops). `TODO(issue)`: re-measure with M29 on a quiet machine.
- `TODO(issue)`, not in M12b (also listed in ADR 0018):
  - **Snippets:** a Code Snippets Manager window; choice lists; a per-snippet tab order.
  - **Editing:** paste with automatic usings, Paste XML as classes, per-language editor options.
  - **Refactorings with options:** Extract Class, Pull Members Up, Move Type and Move Static Members, Encapsulate Field and Introduce Parameter.
  - **Analysis:** an EditorConfig settings UI, a `GlobalSuppressions.cs` suppression file, Error List grouping and the analysis-scope picker, spell checking (D9 open).
  - **Tabs and windows:** pinned and vertical tabs, tab colors, the Ctrl+Tab switcher window, persisted floating documents.
  - **Viewers:** a hex viewer; SVG rendering and animated GIFs.
  - **Bookmarks:** user-defined folders.
  - **Roslyn components:** analyzer, code fix and generator templates.
  - **Go To All:** the persistent index (carried from M12a).
- **Code Metrics** are computed in the host from Roslyn's operations, following `roslyn-analyzers`' documented formulas, rather than through that package's internals. Values can differ slightly from Visual Studio's (for example, how coupling counts generic arguments).
- **IDE0005** is fixed from the compiler's CS8019/CS0105 diagnostics, because Roslyn's fixer needs the IDE's options.
- **Found during validation, fixed:**
  - **macOS (on the M12a snapshot):** the package manager lost its selection when its rows were rebuilt; a wrapped terminal link was not found (links now use logical lines); setting a property to its current value reported a change.
  - **All platforms, under load:** editing a project file could fail with MSBuild's "MSB0001: Should not be dirty now", or on Linux "an equivalent project is already present in the project collection". Both came from evaluation batches running at once in the build host's shared project collection: one started by the edit, one by the file watcher, one by a finished restore. They also came from project-file edits, made in that same collection, changing XML that an evaluation was reading. Evaluation batches now run one at a time (one retry per project on these two errors), and `ProjectFileEditor` edits in its own collection.
  - A new shell test opens a solution through a symbolic link (Linux and macOS) and checks that every project is under the real path and the solution builds.
  - Test waits use monotonic deadlines, so a machine that sleeps during a run doesn't fail them.
  - **macOS:** the build-host integration tests opened their fixtures under `/var/...` while MSBuild nodes and the file watcher report `/private/var/...`. The same project was then restored twice at once (`Core.csproj.nuget.g.props already exists`) or loaded twice. The shell already resolves a solution's path on open; those fixtures now do the same (`RealPath.Resolve`).
  - **macOS:** C# Interactive could send a submission's result before its stderr text when the text had no line break (a timer flush racing the end-of-submission flush). Output is now taken under the send lock.
  - **Code Metrics** missed programs with top-level statements (0 lines for `Hello`, found by the smoke test); they're now one member of `Program`.
  - The smoke step's Duplicate Line check ran with a selection, which duplicates the selection rather than the line.
  - Once on Windows, under load, `Central_package_management_writes_versions_to_directory_packages_props` failed; it passed in three full reruns and alone. `PackageManagerTests.Browse_install_updates_and_uninstall_in_a_project` timed out once the same way and passed three reruns. `TODO(issue)`: watch both.
