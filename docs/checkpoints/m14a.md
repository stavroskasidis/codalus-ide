# M14a checkpoint: Debugger depth

Date: 2026-10-10. Decision: [ADR 0021](../adr/0021-debugger-depth.md). M14b (the debug companion host, dumps, symbol settings) and M14c (remote and special sessions) follow; M15 can start before them.

## Built

**Protocol and adapter** (`DaedalusStudio.Debugging`)
- DAP contracts for `setExpression`, exception filter options, inner exceptions in `exceptionInfo`, and typed `module` events.
- netcoredbg 3.2.0-1092 was probed for what it supports; the results are in ADR 0021.

**Workbench** (`DebugService`, `BreakpointStore`, `ExceptionSettings`)
- **Exception settings:** a list of types that break when thrown, plus a setting for every other type. They are sent as a condition on the `all` filter (`A,B`, or `!A,B` for "all but"). Saved with the solution.
- **Run to Cursor:** a hidden breakpoint at the target, sent with the file's breakpoints and removed at the next stop. **Force Run to Cursor** continues past other breakpoints.
- **Breakpoints:**
  - function breakpoints (`setFunctionBreakpoints`), with their bound state;
  - temporary breakpoints, removed after their stop;
  - dependent breakpoints, inactive until the one they depend on is hit in the session;
  - labels.
- **Inspection:** `setExpression`, the top frame of every thread, the modules from `module` events, and the elapsed time of each stop (PerfTips).

**Shell** (`ShellHost.DebugDepth.cs`, `DebugDepthViewModels.cs`, `DebugAdornments.cs`)
- **Exception helper:** a popup at the statement with the type, message and inner-exception chain. It has View Details (QuickWatch on `$exception`), Copy Details, and "Break when this exception type is thrown".
- **Exception Settings window** (`Ctrl+Alt+E`): search, Break on All / None, Restore Defaults, and custom types.
- **QuickWatch** (`Shift+F9`), a tool window: evaluate, Reevaluate, Add Watch, edit values.
- **Editing values:** `F2` or double-click in Locals, Autos, Watch, QuickWatch and data tips. Watches use `setExpression`; variables use `setVariable`.
- **Data tips** are trees: expand members and edit values (the M5 `TODO`).
- **Context menu on values:** Copy Value, Copy Expression, Add Watch, QuickWatch, and, for strings, View → Text, JSON, XML or HTML Visualizer. A visualizer shows the whole string in a read-only document colored by its grammar; JSON and XML are indented.
- **Execution:**
  - Run to Cursor (`Ctrl+F10`, or with no session: start with a temporary breakpoint there);
  - Force Run to Cursor;
  - Run to Click (`Ctrl`+click in the breakpoint margin while paused);
  - PerfTips at the end of the current line (`debug.perfTips`).
- **Threads** (`Ctrl+Alt+H`): id, name, location, flags, "flagged only", and switching threads. **Modules** (`Ctrl+Alt+U`): order, name, symbol status, optimized, path, and search.
- **Breakpoints window:**
  - function breakpoints and labels;
  - search by location, condition or label;
  - Enable All and Disable All (for the breakpoints shown);
  - Export and Import (JSON), Delete All;
  - a context menu.
- **Breakpoint glyph menu** (right-click in the margin): Delete, Enable or Disable, Conditions and Actions, Labels, Dependency and Temporary (the M5 `TODO`).
- **New commands:** New Function Breakpoint, Insert Temporary Breakpoint (`Shift+Alt+F9`, `T`), Reattach to Process (`Shift+Alt+P`). Also `Ctrl+Alt+B` (Breakpoints) and `Ctrl+Alt+C` (Call Stack) in the classic keyboard scheme.

**Fixture:** `samples/Debugging` gained a `--depth` mode (`Depth.cs`): nested exceptions, a caught `FormatException`, JSON and XML strings, a loop with a call, a settable property and a worker thread.

**Tests**
- **Debugger:** `DebuggerDepthTests` (6) on the real netcoredbg:

**Docs:** ADR 0021, [User guide: Debugging](../user-guide/debugging.md), the shortcut table and the roadmap (M14 split into M14a, M14b and M14c).

## Found along the way

- **Breakpoints were sent again on every answer.** `BreakpointStore.SetStates` raised `Changed`, which made `DebugService` send the file's breakpoints again, and the answer set the states again. It looped for the whole session (since M5). The adapter's answers now raise `StatesChanged`; only edits raise `Changed`.

## Not done, and deviations

- **QuickWatch** is a tool window, not a modal dialog (the shell has no secondary windows). **Run to Click** is `Ctrl`+click in the margin instead of a hover glyph. The **HTML visualizer** shows the source, not a rendering.
- **PerfTips** are measured in the shell from resume to stop, so they include the adapter's overhead.
- **Exception types match exactly**, as netcoredbg matches them: a base type doesn't cover derived types.
- **Budgets:** the proposed debugger budgets aren't measured yet: F10 to updated Locals ≤ 150 ms, a data tip ≤ 100 ms, a 10k-element collection paged. `TODO(issue)`.
