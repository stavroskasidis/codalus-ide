# M36b checkpoint: F# Interactive, scripts, tests and type providers

Date: 2026-10-15. This is the second and last part of M36, the last milestone on the roadmap; with it, M36 is done. It covers F# Interactive in the integrated terminal, scripts, type providers, F# analyzers, Expecto tests in the Test Explorer, and debugging F#. ADR 0068 records the decisions.

## Done

**Research** (before writing code):
- **C# Interactive** is tied to `codalus-replhost`'s protocol.
- **`dotnet fsi`** in a pseudo-terminal: its line editor fails on programmatic input (it asks for the cursor position). `--readline-` reads plain lines, and line directives make its errors name the file and line.
- **FsAutoComplete** checks scripts with `#load` and `#r "nuget:"` itself (tried with Newtonsoft.Json), and type providers once the package is restored (FSharp.Data's `JsonProvider`: `property High: decimal`), without a restart.
- **Expecto:** YoloDev.Expecto.TestSdk 1.0.0 (MIT) needs Expecto 9.x and names tests `<list>.<test>`.
- **netcoredbg in F# code:** breakpoints bind and member paths evaluate (`shapes.Head`), but augmented members (a list's `Length`) aren't found.

**F# Interactive** (`ShellHost.FSharpInteractive.cs`):
- **The session:** a terminal named "F# Interactive" running `dotnet fsi --readline-` (plus `fsharp.fsiExtraParameters`) in the solution's folder, shown in the Terminal window.
- **Sending code:**
  - Send to F# Interactive (`Ctrl+E, Ctrl+E` in F# files, where it replaces C# Interactive's Send; the editor's context menu) sends the selection or the line.
  - Send Line (`Alt+'`).
  - Send File: `#load` for a saved script, else the text.
  - Send References (a project's context menu): builds the project, then `#r` its output and its compile references, without reference packs.
  - Each submission carries a line directive and ends with `;;`.
- **The rest:** Reset F# Interactive; F# Interactive (View → Other Windows); Run Script (`dotnet fsi <script>` in a terminal of its own, for saved `.fsx` files; the new `editorExtension` context key).

**Scripts, type providers, analyzers:**
- **Scripts and type providers** come from FsAutoComplete.
- **Analyzers:** `fsharp.analyzers` and `fsharp.analyzersPath` become FsAutoComplete's `enableAnalyzers` and `analyzersPath`.
- **Trust:** all three run only in trusted folders, with FsAutoComplete (ADR 0067).

**Tests:** Expecto runs through its VSTest adapter in the .NET test plugin, with nothing new in the plugin.

**Fixture** (`samples/FSharp`):
- `FsTests`: Expecto 9.0.4 with YoloDev.Expecto.TestSdk 1.0.0, testing `FsLibrary`.
- `FsData`: FSharp.Data 8.2.0's `JsonProvider` on an inline sample.
- `Scripts/Explore.fsx`, which `#load`s `Helpers.fsx`.

**Tests:**
- **`FSharpInteractiveTests`** (Shell, 3):
  - submissions' line directives, line endings and quoting;
  - Send References' `#r` lines without reference packs;
  - with the real `dotnet fsi`, a selection from `Explore.fsx` answered with `val squares: int list = [1; 4; 9]`, an error that names `Explore.fsx(1,`, and Reset to a new session without the old definitions.
- **`FSharpShellTests`** (Shell; M36a's test, extended):
  - Quick Info in `Explore.fsx` on what `Helpers.fsx` defines, with its documentation;
  - the provided `property High: decimal` in `FsData` once restored.
- **`FSharpTestingTests`** (Shell, 1): `FsTests` is a test project once restored, and running it in the Test Explorer builds it and passes its two Expecto tests, shown under `Shapes`.
- **`FSharpDebuggingTests`** (Debugging, 1), on the real netcoredbg:
  - a breakpoint in `Geometry.fs` binds and stops, with the `shapes` parameter;
  - `shapes.Head` and `1 + 2` evaluate;
  - the call stack includes `Program.fs`.
- **Smoke step `fsharp.interactive`:** a selection from the script answered in F# Interactive (screenshot `fsharp-interactive.png`). `fsharp.editing` now waits for the solution's five projects.
