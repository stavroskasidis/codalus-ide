# M13a checkpoint: Git depth

Date: 2026-10-10. Decision: [ADR 0020](../adr/0020-git-depth.md). M13b (hosting integration, askpass, worktrees, LFS) follows; M14 can start before it.

## Built

**Workbench** (`GitService.History.cs`, `GitService.Operations.cs`, `GitGraph`)
- **History:**
  - pages of `git log --topo-order`, with filters: every branch or one revision, author, message, path (`--follow` for a file), dates;
  - commit details: the message and the changed files, renames included;
  - line history (`git log -L`);
  - revisions resolved to commits.
- **The graph:** `GitGraph` gives each commit a lane and the line segments of its row, page by page. The state carries over pages.
- **Operations in progress:** `GitStatus.Operation` (merge, rebase, cherry-pick, revert); Continue (without an editor), Skip, Abort.
- **Conflicts:** the three stages (base, ours, theirs); resolving with a text or a whole side.
- **Commits and branches:**
  - stash: push (partial by path, untracked optionally), list, apply, pop, drop;
  - cherry-pick, revert, reset (soft, mixed, hard), detached checkout, a branch at a commit;
  - rebase, and interactive rebase from a todo list (reword through `exec git commit --amend`; squash keeps the messages).
- **Tags:** list, create (annotated or lightweight), delete, push, delete on a remote.
- **Remotes:** list, add, rename, set the URL, remove.
- **Per-line staging:** `FileDiff.PatchForLines` builds sub-hunk patches for stage, unstage and discard.
- **Repositories:** Add to .gitignore, the commit template, submodule status and update, init with a .NET `.gitignore`, and clone.

**Shell** (`ShellHost.GitDepth.cs`)
- **History window:**
  - the graph (`GitGraphCell`), refs, author, date and hash;
  - filters; paging on scroll;
  - details and changed files; a file opens as a diff against the parent;
  - commit commands on the context menu.
- **File history** (the editor and Solution Explorer), **line history** (editor context menu), **Show Commit for Line** (blame), and **Compare with Branch or Commit** (revision diffs: `DiffViewModel` takes two text providers).
- **Merge editor:** current and incoming above, the result below with the conflicts highlighted. Accept Current, Incoming or Both (one or all); previous and next conflict; Accept Merge once none are left.
- **Git Changes:**
  - a banner for the operation in progress, with Continue, Skip and Abort;
  - conflicts open in the merge editor;
  - Stash, Stashes and History buttons;
  - the commit template prefills an empty message.
- **Interactive rebase editor:** reorder, and pick, reword, squash, fixup or drop; started from the Git menu or a commit in the history.
- **Diff view:** Stage, Unstage and Discard Selected Lines.
- **Commands and menus:**
  - Git menu: Clone, Create Repository, History, Continue/Skip/Abort, Stash, Stashes, Rebase, Interactive Rebase, Tags, Remotes, file and line history, Show Commit, Compare with, Update Submodules;
  - the editor's and the Solution Explorer's context menus;
  - `Ctrl+0 Ctrl+H` for the history.
- **Command line:**
  - `daedalus merge LOCAL REMOTE BASE MERGED` (git mergetool) and `daedalus --wait FILE` (core.editor), answered by the running window or by a new one that exits with the outcome;
  - the single-instance pipe now serves clients concurrently and can wait for an answer.

## Found during validation

- **Half-written RPC frames.** `JsonRpcConnection` and `DapConnection` passed the caller's token to the header and body writes. A request cancelled between the two (a superseded completion, a debounced package search) left a header with no body, so the peer read the next message as that body. The language service then stalled with the host idle on stdin (seen in the Mac and Windows Native AOT smoke tests and as rename test timeouts), and the build host dropped the connection ("The connection was lost" in the package manager). Now only the wait for the write lock can be cancelled. Regression test: `A_request_cancelled_while_its_frame_is_written_leaves_the_stream_intact`.
- **RPC diagnostics.** `JsonRpcConnection.Slow` reports requests running for over 10 s, notifications handled for over 2 s and writes blocked for over 10 s. The shell writes the language service connection's reports to its output channel, and the language service host logs its own. The language service also reports when its start stalls.
- **The terminal lost output on macOS.** `UnixPseudoTerminal` closed its copy of the slave side right after spawning, so when the child exited, the output still in the buffer could be discarded. It now keeps the slave open until the child has been reaped.
- **Diagnostics cancellation** no longer runs under the diagnostics lock.
- **Package manager:** loading the installed packages is retried once (a project file read while a restore writes it can fail).
- **Tests:** a build test waited for the IntelliSense row in the Error List instead of the build's; the rename test waits for its diagnostics.
