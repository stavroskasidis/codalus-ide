# M29 checkpoint: a classic IDE's look and feel

Date: 2026-10-10. Decision: [ADR 0019](../adr/0019-classic-ide-look-and-feel.md). Requested by the maintainer on 2026-10-10 ("closer to Visual Studio"), between M12 and M13. Next: M13.

## Built

**Title row and search**
- The menu, a search box and the solution's name in one row. On Windows it's the window's title bar: the client area extends into it, the empty part drags, a double click maximizes. Elsewhere it sits under the system's title bar; macOS keeps its global menu.
- **Search** (Ctrl+Q, `workbench.action.featureSearch`): commands with their keys, settings (they open in Settings, filtered), files, and the solution's types and members. The terminal leaves Ctrl+Q to the IDE.

**Standard toolbar** (`ToolbarViewModel`, `ShellHost.Toolbar.cs`)
- Back, forward, open, save, save all, undo, redo.
- The solution configuration and platform. Choosing one switches the active configuration.
- The startup project. Start shows the project and its launch profile; Start Without Debugging is next to it.
- While debugging: Continue (when stopped), Break All, Stop, Restart, Step Into, Over and Out.

**Themes**
- Blue (new), Light and Dark in Visual Studio 2022's colors; High Contrast as before. Blue uses Light's editor, grammar and terminal colors.
- New tokens: title bar, toolbar, search box, tabs and active caption. Dock's active tab, tab strip, surfaces and active caption brushes are mapped onto them.
- **The status bar's state:** purple without a solution, the accent with one, orange while debugging, and "Ready" when there's no message. The Git branch moved to the right. The theme indicator is gone, and the configuration and startup project moved to the toolbar; a running program still shows, with a stop button.

**Keyboard schemes**
- Setting `keyboard.scheme`: `default` or `vscode`, via the `keyboardScheme` context key and `when` clauses in the default bindings.
- The default scheme: F6 builds, Ctrl+Q searches, Ctrl+, goes to anything, F1 is help in the editor, Ctrl+K Ctrl+S surrounds with a snippet, Ctrl+F4 closes, Alt+F6 and Alt+Shift+F6 move between panes, Ctrl+Alt+L shows the Solution Explorer and Ctrl+Alt+O the Output.
- The VS Code scheme keeps the previous keys.

**Layout, Solution Explorer, Options**
- The Solution Explorer opens on the right.
- It gained a toolbar (Home, Sync with Active Document, Collapse All, Properties) and a search box (Ctrl+;) that filters the tree to the matches and their parents.
- Settings are an Options tree of groups (Environment, Text Editor, Projects and Solutions, Debugging, Source Control, Testing, Terminal and Interactive, Other) with their categories. Tools → Options… opens it; the theme and keyboard commands moved to the Tools menu.
- 12 px (9 pt) UI text.

**Also**
- Command titles name file formats rather than another product: "Import Snippets (.snippet)…" and "Import Test Playlist (.playlist)…".
- Saving a project file retries a Windows sharing violation, seen once while an evaluation read it.

**Tests**
- **Headless UI** (`ChromeTests`):
  - the toolbar following and switching the configuration, the startup project and the debug state;
  - the status bar's states;
  - the search box (commands, settings, files);
  - Solution Explorer search, sync and Home;
  - the Options tree;
  - both keyboard schemes;
  - the Blue theme's colors.
- Updated tests for the moved status items, the new keys and the menu.
- **Smoke test:** step `shell.chrome` (M29) checks the toolbar, title and status bar with BuildAndRun open, and saves `smoke-test-theme-{blue,light,dark}.png`. `shell.themes` includes Blue.
- `EditorTests` now reports what the shell and language service did when the rename preview doesn't come (seen twice under load).

**Docs**

- [User guide: the window, settings, themes and keyboard shortcuts](../user-guide/settings.md), the shortcut table, editing, terminal and testing pages.
- CLAUDE.md, README and the roadmap.

## Not done, and deviations

- **Dock's brushes:** Dock uses its foreground brushes in more places than their names say. So only the active tab's colors are themed, and Blue's dark inactive tabs aren't reproduced.
- **macOS:** the screenshots capture the client area only, so the native title bar and global menu were not checked in them (the Mac session offered a real window capture).
- **Visual details, from the Mac's review of the screenshots:**
  - the Solution Explorer's root label is cut without an ellipsis in a narrow panel;
  - the Test Explorer's filter row wraps in a narrow window;
  - Light's muted text (the Start page's "On") is faint.
