# M15b checkpoint: Hot Reload

Date: 2026-10-10. Decision: [ADR 0022](../adr/0022-aspnet-core-loop.md), "Hot Reload (M15b)". M15c (scaffolding, service references) follows; M16 (Razor and Blazor) can start before it.

## Built

**Workbench**
- `RunService.StartAsync(…, hotReload: true)` runs the project under `dotnet watch run --no-launch-profile --non-interactive`, with the same plan as Run: the launch profile's environment, URLs and arguments, and the environment selector. `RunService.HotReloadPlan` builds it with the solution's SDK (`DotnetRoot`). The environment adds:
  - `DOTNET_WATCH_SUPPRESS_EMOJIS=1`: plain messages;
  - `DOTNET_WATCH_RESTART_ON_RUDE_EDIT=true`: restart instead of asking;
  - `DOTNET_WATCH_SUPPRESS_LAUNCH_BROWSER=1`: the IDE opens the browser, as for Run.
- `HotReloadOutput` reads the watch's lines (applied in N ms, compile errors, restarting, waiting, exited), matching loosely across SDK wordings. `HotReloadSession` keeps the state, the last apply time and the counts of updates and restarts.

**Shell** (`ShellHost.HotReload.cs`)
- **Debug → Start with Hot Reload**, and **Apply Code Changes** (`Alt+F10`, saves every modified document).
- The **Hot Reload on Start Without Debugging** setting (`run.hotReload`) makes `Ctrl+F5` use it.
- **A status bar item** (a flame): starting, watching, applied in N ms, compile errors, restarting, exited. Click it to see the output.
- **A notification** when a rude edit restarts the app. The `hotReloadRunning` context key.

**Checked by hand:** browser refresh works with this setup. `dotnet watch` injects `aspnetcore-browser-refresh.js` into the app's HTML responses to browsers, although the IDE launches the browser.

**Tests**
- **Workbench:** `HotReloadOutputTests`: the lines of two SDKs' wordings, ignored lines, and a session's counts.
- **Headless UI:** `WebTests.Hot_reload_applies_a_saved_edit_to_the_running_app`: the web fixture under `dotnet watch`. An edit of a handler, saved through Apply Code Changes, changes the running app's answer. The status bar item and the context key are checked.
- **Smoke test:** step `web.hotReload` (M15): the same edit in the shipped app.

**Docs:** ADR 0022 (the run's details), [User guide: Web development](../user-guide/web.md) (Hot Reload), the shortcut table and the roadmap.

## Not done, and deviations

- **Not while debugging:** netcoredbg can't apply metadata updates (ADR 0021). A debug session restarts instead.
- **No Hot Reload toolbar button with a dropdown** (Hot Reload on save, restart); the Debug menu and the setting cover it. `TODO(issue)`, M23 (toolbar customization).
- **Budget:** "Save → change active ≤ 1 s" isn't measured as a benchmark. `dotnet watch` reported 116–1,203 ms on this machine (the first update includes its warm-up). `TODO(issue)`.
- **M15c** (scaffolding, OpenAPI and gRPC service references) is next in M15; M16 doesn't depend on it.
