# M20a checkpoint: Android devices and running MAUI apps

Date: 2026-10-14. The first part of M20 (.NET MAUI, D6). Decision: [ADR 0064](../adr/0064-mobile-devices-and-android-runs.md).

## Built

**The Android SDK and JDK** (`AndroidSdk`, workbench `Mobile/`).
- Found from `ANDROID_HOME`/`ANDROID_SDK_ROOT` and `JAVA_HOME`.
- Otherwise from the folders Android Studio, Visual Studio's installer and the workload's `InstallAndroidDependencies` use on each OS; the newest JDK wins.
- Builds get both as `AndroidSdkDirectory` and `JavaSdkDirectory`.

**Devices** (`AndroidDevices`).
- `adb devices -l` lists running devices and emulators with their state (`unauthorized` and `offline` are shown); `adb emu avd name` matches an emulator to its virtual device.
- `emulator -list-avds` adds the virtual devices that aren't running, named from `config.ini`.
- An emulator starts in its own window, and the IDE waits for `sys.boot_completed`.
- Apps are launched (`monkey … LAUNCHER`), found (`pidof`) and stopped (`am force-stop`).

**Running** (`AndroidRunner`, `MobileProjects`).
- A mobile app is an executable with an `-android`, `-ios` or `-maccatalyst` framework.
- Start Without Debugging:
  1. starts the toolbar's emulator if needed;
  2. builds and installs the Android framework only, through the build host's `Install` target with `AdbTarget`;
  3. starts the app, and streams `adb logcat --pid` into its Run channel.
- Stop (a new `RunningProgram.Stopping` hook) also stops the app on the device.
- F5 says that debugging on a device comes later (M20b).

**The shell** (`ShellHost.Mobile.cs`).
- The standard toolbar's **device list** (`DeviceChoice`, `ToolbarViewModel.Devices`) shows while the startup project is a mobile app.
- **View → Devices** is a declarative window: devices with their kind, state and serial, Refresh, and double-click to choose (starting an emulator). It also shows the SDK and JDK in use.
- One device listing runs at a time, and callers share it.
- A new `phone` icon (Fluent).

**Fixture**: `samples/Maui` (`MauiCounter`):
- the .NET MAUI template for Android, iOS and Mac Catalyst (the Windows target is out of scope);
- a view model bound with compiled bindings, with a `// [debug]` line for M20b;
- a platform-specific `PlatformName.cs` in each platform's folder.

## Tests

- **Workbench** `MobileTests` (4):
  - the SDK and JDK search order (`ANDROID_HOME` first, then the installers' folders, the newest JDK);
  - parsing `adb devices -l` and `emulator -list-avds`;
  - the device list with a stand-in adb and emulator: a running emulator matched to its virtual device and not listed twice, an unauthorized device;
  - mobile project detection.
- **End to end** `MobileShellTests` (with `CODALUS_TEST_ANDROID=1`): the shell opens `samples/Maui`, picks an emulator in the toolbar, and Start Without Debugging builds, installs and starts the app. The app's process is found on the emulator; Stop stops it. The emulator is stopped when the test started it.

**Validation**: Windows (this machine has the Android SDK, OpenJDK and two emulator images from Visual Studio's installer).
