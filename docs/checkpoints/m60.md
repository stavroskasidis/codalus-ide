# M60 checkpoint: the IDE's tools for agents, round 2

Date: 2026-11-13. The roadmap's [M60](../roadmap.md#m60--the-ides-tools-for-agents-round-2), D50 and D52 ([ADR 0099](../adr/0099-the-ides-tools-for-agents-round-2.md)). One pull request.

## Done

Every new tool joins `IdeTools.BuiltIn` (round 2's groups in `IdeToolsRound2`) and passes round 1's dispatcher: paths confined to the workspace, excluded files left out, answers redacted and cut to size, a line in the AI Output channel per call, now with its duration. Read tools change nothing and run none of the workspace's code; actions follow `ai.agent.ideActions`.

**Code changes.** `rename_symbol` (the language service's rename, across files), `get_code_actions` (Read) and `apply_code_action` (the light bulb's fixes and refactorings at a line, by title or index; a refactoring's dialog takes its defaults), `format_document`, `replace_in_files` (Replace All's engine, now shared as `PlanReplacementsAsync`). An open file changes as one undo step and stays unsaved; a closed one is written; a change that would touch a file outside the workspace, excluded from AI or read-only is refused whole; the answer lists each changed file. Files the tools wrote are read again by the C# host before the next tool, which fixed a stale second format found by the tests.

**Hot Reload and profiling.** `apply_code_changes` under the Codalus debugger (rude edits and errors returned as `ENCxxxx` lines, no question to the user) and under `dotnet watch`; `profile_start` and `profile_stop` (the program being debugged or run, or a project launched under the profiler; the hot path and the top functions by self and total time, with source lines); `memory_snapshot` (the largest types, and the heaviest root path of the top three).

**Services.** `list_services` (compose services from the workspace's compose files and `.dcproj`s, and a running AppHost's Aspire resources with their state and endpoints), `service_start`, `service_stop`, `service_restart` and `service_debug` (as the Containers and Aspire windows do), `service_logs`; `service_traces` and `service_metrics` say the resource service has none and point at the dashboard.

**Packages and migrations.** `list_packages`, `search_packages`, `add_package`, `update_package` (central versions by default, an override on request), `remove_package`, through the Package Manager's `PackageService`; a package that needs its license accepted is refused. `list_migrations`, `add_migration`, `apply_migrations` (a revert only with `allowRevert`), `script_migrations`, through the Entity Framework window's flow and the user's `dotnet-ef`; listing and scripting are actions, since they build and run the startup project.

**Git.** `git_status`, `git_diff`, `git_log`, `git_file_history`, `git_blame`, `git_conflicts` (Read); `git_stage`, `git_unstage`, `git_commit` (the user's identity, no trailers, never an amend), `git_stash`, `git_checkout`, `git_resolve` (ours, theirs, both, or content without conflict markers). No push, pull, fetch, reset, rebase, amend, force or branch deletion; a test checks no tool or parameter offers them. Excluded files are counted, never named or shown, and never staged, committed or stashed.

**The IDE.** `list_commands`, `run_command` (under the command's enablement; a public deny list of exact ids, prefixes and words, and the command sweep's skips; dialogs and pickers it opens are cancelled), `get_settings` (secret-looking values masked; never `SecretStorage`), `ide_screenshot` (refused while a document outside the workspace or excluded from AI shows), `terminal_send`.

**Long calls.** `codalus mcp` sends `notifications/progress` every 10 seconds while a call runs, when the client sent a progress token.

**Agents outside the IDE.** The first call in a folder through the general pipe asks: Allow, Always for This Folder (`ai-outside-agents-allowed.json` in the state folder) or Don't Allow (the default); unanswered for two minutes, the call is refused. Listing the tools never asks. **Set Up Agents Outside the IDE…** (`ai.mcpServer.setup`) shows Claude Code's, Codex's, Gemini CLI's, GitHub Copilot CLI's and `.mcp.json`'s setups with this install's path, each with a Copy button, and offers to turn MCP Server on. `codalus mcp`'s instructions name round 2's tools.

**Docs.** The user guide (AI › The IDE's tools, Codalus as an MCP server), the Features page, ADR 0099, the changelog and the roadmap (D52).
