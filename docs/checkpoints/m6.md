# M6 checkpoint: Git

Date: 2026-10-09. Plan and decisions: [ADR 0008](../adr/0008-git.md). Git uses the git CLI rather than LibGit2Sharp: it brings the user's configuration, credential helpers, SSH, hooks and every repository format, with no copyleft native library in the distribution.

## Built
- **`GitService`** (workbench) runs one `git` process per operation and parses porcelain output.
  - Status (`porcelain=v2`, branch, ahead/behind, merges in progress), refreshed after operations and on debounced file-system changes.
  - Stage, unstage and discard per file (an untracked discard deletes the file, after a confirmation).
  - Per-hunk stage, unstage and discard (`git apply --cached`/`-R` with a one-hunk patch).
  - Commit, commit all, amend.
  - Branches: list, switch (remote branches get a tracking branch), create, merge (conflicts listed), abort merge.
  - Fetch, pull, push (the first push sets the upstream).
  - Blame of the editor's text (`--contents -`, so it lines up with unsaved edits).
  - Index and HEAD versions of files.
- **Line diff**: Myers, with a bounded edit distance and memory, for gutter markers and side-by-side alignment.
- **Shell**:
  - The **Git Changes** window: branch with ↑/↓, fetch/pull/push, commit message (Ctrl+Enter), Commit Staged, Commit All, Amend, merge banner with Abort, merge conflicts, staged and unstaged lists with per-row stage, unstage and discard, Stage All and Unstage All; double-click opens the diff.
  - **Diff documents**: side by side, with aligned rows and synchronized scrolling, or inline. Previous and next change; Stage, Unstage or Discard the hunk at the caret.
  - **Editor**: change markers in the gutter (added, modified, deleted, against the index, updated as you type) and blame annotations (Ctrl+Alt+B).
  - A **Git menu**, a branch item in the status bar (click to switch or create), and the context keys `gitRepository` and `gitMerging`.
- **Tests**:
  - Git integration against real throwaway repositories: hunks, staging, discard, untracked files, commit and amend, branches, merge conflicts and abort, push, fetch and pull with a bare remote, blame of committed and uncommitted text.
  - Unit tests: the line diff (random round trips), the porcelain parser, hunk headers.
  - A headless UI test: gutter markers while typing, the Changes view, hunk staging in the diff document, commit, blame, a new branch in the status bar.

## Deviations and gaps
- Git is built in, not a plugin: the plugin API has no editor extension points for diff documents, gutter markers or blame margins yet. `TODO(issue)`: a source-control contribution point.
- Conflicts are listed, but there is no three-way merge editor: resolve in the file (conflict markers), then stage. `TODO(issue)`.
- Not in M6: stash, rebase, cherry-pick, history/log view, tags, multiple repositories per solution, submodules. `TODO(issue)` (post-MVP).
- Fetch, pull and push rely on the user's credential helper. With terminal prompts disabled, a missing helper fails with git's message instead of prompting.
- Discarding an untracked file deletes it with `git clean` (after a confirmation), not to the OS trash. `TODO(issue)`.
