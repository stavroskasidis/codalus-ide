# M22d checkpoint: components, offline layouts and plugin performance

Date: 2026-10-13. Decision: [ADR 0061](../adr/0061-components-and-plugin-performance.md). With M22a ([m22a](m22a.md)), M22b ([m22b](m22b.md)) and M22c ([m22c](m22c.md)) this completes M22.

## Built

- **The component catalog** (`ComponentCatalog`, workbench `Components/`). The components are Node.js, the web language servers, vscode-js-debug, netcoredbg for remote targets and the converted icon themes.
  - Each declares its version, licence, description, folders under the cache, an installed check and its own install.
  - The catalog gives each one's status and size, removes it, and exports and imports offline layouts: the folders at their cache paths, plus `components.json`. Import takes only the components this IDE uses, at its version, that aren't there yet, and refuses paths outside the layout.
- **The Components window** (Tools → Components…, `ShellHost.Components.cs`, a declarative view): the table, **Download Now**, **Remove**, **Export Offline Layout…**, **Import Offline Layout…** and **Refresh**.
- **Plugin performance**:
  - Each plugin's activation time, command calls and slowest call (`PluginDescription.ActivationTime` and `Commands`), and each local host's memory (`PluginManager.HostMemory`), on the Plugins window's rows.
  - An activation over two seconds raises `SlowPlugin`. After three sessions in which a plugin was slow, a notification offers **Turn It Off** (`ShellHost.PluginPerformance.cs`).

## Tests

- **Workbench** `ComponentCatalogTests`: status and sizes, removing; a layout exported, then imported into another cache with a component of another version left out; a folder that isn't a layout refused.
- **Plugins** `PluginPerformanceTests`: the activation time, two commands counted, the host's memory, and the slow-activation event, through a real plugin host.
- **Headless UI** `ComponentsWindowTests`: every component listed with its licence, the actions for a selected one, and an import refused.

**Validation**: Windows green on the affected classes; the full suite and the other OSes come with the push.

## Not done

- The SDK and the IDE's own installer aren't part of a layout (ADR 0061).
- Memory per plugin inside a shared host isn't measured; a dedicated host gives one plugin its own.
