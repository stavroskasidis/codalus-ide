# M48 checkpoint: external agents over the Agent Client Protocol

Date: 2026-10-18. The maintainer's M48 ([roadmap](../roadmap.md#m48--external-agents-over-the-agent-client-protocol)): AI Chat runs external coding agents (pi through pi-acp, Claude through its ACP adapter, Codex, Gemini CLI, GitHub Copilot, OpenCode, Goose…) next to the built-in agent, over the Agent Client Protocol (ACP, protocol version 1). The IDE serves their file, terminal and permission requests with its own checks, and gives every agent its tools through `codalus mcp`. Decisions: D34, the maintainer's exception to the AI boundary (off by default, user settings only, trusted workspaces only, labeled), recorded in [ADR 0079](../adr/0079-external-agents-over-the-agent-client-protocol.md) with the client's design.

## Done

**The client** (`Codalus.Workbench/Ai/Acp/`):
- **Types** (`AcpProtocol.cs`): written by hand from the official schema, `schema/v1/schema.json` of agent-client-protocol 1.12.0 (2026-10-16), noted in the code (`AcpVersion`); source-generated `AcpJsonContext`, so the shell stays Native AOT clean. No community .NET ACP package (unofficial; dotacp uses reflection-based StreamJsonRpc).
- **Transport** (`Codalus.Rpc`): `JsonRpcConnection` gains newline-delimited framing (`JsonRpcFraming.NewlineDelimited`, `LineMessageReader`: blank and non-JSON lines skipped) and a configurable cancel notification (`JsonRpcCancelNotification.Acp`: `$/cancel_request` with `requestId`, both ways); `SupervisedProcess.Framing`.
- **`AcpClient`**: starts the agent with `SupervisedProcess` (no restarts: its session lives in the process; no shutdown request: closing stdin ends it; a Windows `.cmd` such as `npx.cmd` through `cmd.exe`), `initialize` with protocol version 1 (another version is refused with what the agent speaks), `authenticate`, `session/new` (an `auth_required` answer carries the agent's sign-in methods), `session/prompt` (it completes after the updates sent before the answer are handled), `session/set_mode`, `session/cancel`. Advertised: `fs.readTextFile`, `fs.writeTextFile`, `terminal`, `session.compaction`, `session.notices`. Not advertised: `auth.terminal`, `elicitation`.
- **`AcpAgentSession`** (one chat session): `session/new` with `cwd` = the workspace root, no `additionalDirectories`, and `codalus mcp`; the updates into the turn (message and thought chunks, the plan, tool calls and updates as steps with kind, title, status, locations, diffs, text and terminal output; available commands and the current mode on the session; notices and compaction notices); the agent's requests (below); Stop as `session/cancel` (pending permissions answered `cancelled`, pending approvals closed, the turn's commands killed, unfinished steps cancelled, 10 seconds' grace for the agent's `cancelled`); a crash ends the turn with the agent's last lines of standard error.
- **`AcpAgents`**: `ai.agents` read from the user's settings only (a workspace can't add one), the gate (`WhyNot`: AI on, a workspace, a trusted one), and the one running session: reused while it's alive and the agent, settings and workspace are the same, stopped on New Chat, another agent, the workspace closing or changing, and exit.
- **`AiChat.SendExternalAsync`**: the context chips go through `AiService.PrepareAsync` before they are put in the prompt; `AiService.LogExternalPrompt` and `LogAgent` write the AI Output channel; the busy state shows Stop and "AI: working…".

**Serving the agent's requests** (the IDE's checks, ADR 0063's, through `WorkspacePaths`, now shared with agent mode):
- `fs/read_text_file`: the editor's buffer or the disk; `line` (1-based) and `limit`; refused outside the workspace (links included) and for excluded files; redacted.
- `fs/write_text_file`: the refactoring preview of the whole-file change, answered after Apply (into the editor's buffer, opening the file first; unsaved, one undo step; a new file on the disk) or Reject (a JSON-RPC error: "The user rejected the change to … Don't make it again; ask what they want instead.").
- `session/request_permission`: the approval dialog with the title, kind, raw input (indented JSON) and diffs; **Allow Once**, **Reject**, **Always Reject**; `allow_always` not offered; Reject the default; `cancelled` on Stop.
- `terminal/create`, `output`, `wait_for_exit`, `kill`, `release`: approved first with the exact command line and folder; run through the IDE's process launcher (`IProcessLauncher`; a command without arguments that has spaces through `/bin/sh -c` or `cmd /c`); output within the agent's byte limit, cut from the start at a character boundary; live and redacted in the step and for the agent; stopped after `ai.agent.commandTimeoutSeconds`; killed on Stop; freed on release.
- `authenticate`: the agent's methods in a dialog that says the agent manages its own sign-in and Codalus doesn't see or keep its credentials; the chosen one runs, then `session/new` again. Codalus stores nothing.
- Diffs an agent applied itself (no `fs/write_text_file`): read-only in the step ("made by the agent itself"), an open editor reloaded (asking first when it has unsaved changes), logged as not reviewed.

**`codalus mcp` per session** (`McpBridge.SessionPipeName`, `--agent-session`): the entry is the running executable's absolute path (or `dotnet` with `codalus.dll`), `mcp`, `--user-data-dir` (when the IDE has one) and `--agent-session <token>`; the IDE opens `<instance pipe>-a<token>` for the session only (current user only), even with `ai.mcpServer.enabled` off, and closes it with the session. Calls are logged with the agent's name.

**AI Chat** (`AiChatViewModel`, `AiChatView`, `ShellHost.Acp.cs`):
- The agent picker (Built-in, then each agent; shown once one is configured; another choice starts a new chat), the mode picker (when the agent has modes), the label ("External agent: uses its own provider and data policy. Codalus checks what it asks the IDE for.") whenever an external agent is chosen, and under it why the agent can't run (AI off, no folder, an untrusted folder), with Send disabled. The provider, Configure and Agent controls are the built-in assistant's and hide.
- A turn shows which agent answered, its thinking (collapsed under **Thinking**), its plan (☑ ◐ ☐), its steps (✓ ◐ ✗ ⊘, kind and title; locations as links that open the file at the line; diffs and output in expanders that keep their state across renders; output open while a command runs), the answer, and its notices.
- `/` offers the agent's commands under the box; `Tab` or a click takes one.
- Existing styles and classes only (`toolbar`, `link`, `muted`, `Shell.Info`, `Shell.Warning.Foreground`), so the M34h control set and the coming AI Chat redesign can restyle it.

**Docs and site:** ADR 0079; CLAUDE.md's AI rule names the exception; the user guide's [External agents (ACP)](../user-guide/ai.md#external-agents-acp) (setup, pinned examples for pi, Claude, Codex and Gemini from the ACP registry, what you see, the safety model and its limits) and its settings table; `codalus --help` (`--agent-session`); the roadmap (status row, M48, D34, change log); the website's Features page; `CHANGELOG.md` (0.4.0). No new `CODALUS_*` variable (the stand-in's `ACP_FAKE_*` are the tests'). No plugin API change.

- **`AcpShellTests`** (Shell, headless, 2, new), with the real `codalus mcp`: the picker (Built-in and the agent), the label and the hidden provider; without a folder the chat says why and Send is off; in a trusted BuildAndRun the turn's thought (collapsed), plan and agent line; `session/new`'s `cwd` and `codalus mcp` (`dotnet` and the absolute `codalus.dll`, `--user-data-dir`, `--agent-session`); `codalus mcp` started from that entry reaching this IDE's `get_solution` with `ai.mcpServer.enabled` off, logged with the agent's name; a read step's location opening Greeter.cs; a command's approval with its exact line, refused by Enter; a permission's three buttons, Reject the default, the diff and raw input in the details; a write's preview applied into the buffer (modified, the disk unchanged) and its reviewed diff; New Chat stopping the agent and closing its pipe.
