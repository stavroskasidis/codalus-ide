# M36a checkpoint: F# editing and the compile order

Date: 2026-10-15. This is the first part of M36, the last milestone on the roadmap. F# files are served by FsAutoComplete through the LSP bridge (D10) and formatted by Fantomas. Solution Explorer shows and edits an F# project's compile order. ADR 0067 records the decisions. M36b, next, covers F# Interactive, scripts, Expecto tests, type providers and analyzers.

## Done

**Research** (before writing code, against FsAutoComplete 0.85.3 driven over stdio by a scripted client):
- **Tools:** FsAutoComplete and Fantomas are .NET tools on nuget.org, both Apache-2.0. FsAutoComplete has net8.0, net9.0 and net10.0 builds. Fantomas 7.0.3 is net8.0 and rolls forward.
- **Projects:** with `AutomaticWorkspaceInit`, FsAutoComplete loads the root folder's solution itself (Ionide.ProjInfo with MSBuild), `.slnx` included, in about 7 s for `samples/FSharp`.
- **Diagnostics** need the client's `publishDiagnostics` capability, which ours declares.
- **Settings** come from an `FSharp` section of `workspace/didChangeConfiguration`.
- **Formatting** needs a Fantomas it can find: a local tool, a global tool, or `fantomas` on `PATH`.
- **C# references** are read from the C# project's built reference assembly.
- **Protocol details:** a `command:` link in hover; token types `member`, `module`, `cexpr`…; the references lens's three arguments; no `codalus/` requests.

**The language service:**
- **`FSharpTools`** (workbench `FSharp/`): FsAutoComplete 0.85.3 and Fantomas 7.0.3 installed with the user's `dotnet tool install --tool-path` into `<cache>/fsharp/<tool>/<version>`.
  - It runs from the cache folder, so a solution's `global.json` or tool manifest doesn't apply, and an install that fails leaves nothing behind.
  - A cache lock lets windows and test assemblies share the cache.
  - FsAutoComplete starts with `dotnet`, `DOTNET_ROOT`, and Fantomas's tool path last on `PATH`.
- **The shell** (`ShellHost.FSharp.cs`):
  - **Registration:** the `fsharp` descriptor (`.fs`, `.fsi`, `.fsx`, `.fsscript`), with `AutomaticWorkspaceInit`.
  - **The install:** offered on the first F# file. The setting `fsharp.languageService` is `ask`, `install` or `off`. You can also use the command Install the F# Language Service, or Tools → Components (the `fsharp` component).
  - **Trust:** FsAutoComplete starts only without a solution or in a trusted one. It starts again when a solution opens or becomes trusted (`LanguageService.RestartAsync`).
  - **Settings:** `fsharp.completeUnopenedNamespaces`, `fsharp.linter`, `fsharp.inlayHints`, `fsharp.signatureCodeLens` and `fsharp.referencesCodeLens` go out as FsAutoComplete's `FSharp` section (`LanguageServiceDescriptor.Settings`, a new hook that applies to any server).
- **The bridge,** for any server:
  - `command:` links are removed from hover Markdown;
  - FsAutoComplete's token types are aliased;
  - a CodeLens's position is its second argument whatever follows it, and `fsharp.showReferences` is Find All References;
  - `codalus/testCandidates` failures are skipped per language, where one server's failure used to drop the whole batch;
  - `codalus/documentOptions` isn't asked of FsAutoComplete or the web servers.

**The compile order:**
- **The build host:** `items/move` (`ProjectItems.Move`) moves a `Compile` include before or after another. In an F# project, a new `Compile` include goes after the last one, or before it in a program, instead of `AddItem`'s alphabetical place, and `.fsi` files are included as `Compile`.
- **Solution Explorer** (`SolutionTree.IsOrdered`):
  - F# projects show compiled files in compile order. A folder sits at its first file, and the rest follow by name.
  - `Shapes.fsi` nests under `Shapes.fs`.
  - **Move Up** and **Move Down** (`Alt+Up`, `Alt+Down`, the context menu) move a file and its signature file within its folder (`CompileOrder.Step`).
  - **Add Above** and **Add Below** open Add New Item and place the new file (`AddNewItemViewModel.Placement`).
- **Item templates:** Source File, Class, Interface, Record, Signature File (`Compile`), and Script File.
- **Property pages:** `ProjectPropertyPages.FSharp`, with Nullable, the F# version, `WarnOn`, `OtherFlags` and Tail calls, and without unsafe code, warning level or implicit usings.

**Fixture:** `samples/FSharp`: `FsLibrary` (`Shapes.fsi`, `Shapes.fs`, then `Geometry.fs`, which uses them), `FsConsole` (uses both libraries) and `CsLibrary` (C#), with a Fantomas `.editorconfig`.
