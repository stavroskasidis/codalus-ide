Daedalus Studio packages

apt and dnf repositories for Daedalus Studio. Installs from them update with the system. Use stable for releases or nightly for nightly builds. The packages need the .NET SDK and git.

Debian and Ubuntu (apt)

curl -fsSL {{BASE_URL}}/daedalus-studio-packages.asc | sudo gpg --dearmor -o /usr/share/keyrings/daedalus-studio.gpg
echo "deb [signed-by=/usr/share/keyrings/daedalus-studio.gpg] {{BASE_URL}}/apt stable main" | sudo tee /etc/apt/sources.list.d/daedalus-studio.list
sudo apt update && sudo apt install daedalus-studio

Fedora and RHEL (dnf)

sudo curl -fsSL -o /etc/yum.repos.d/daedalus-studio.repo {{BASE_URL}}/rpm/daedalus-studio-stable.repo
sudo dnf install daedalus-studio

Other downloads (Windows, macOS, the AppImage) are on the releases page.
