# WinForms, WPF and WinUI 3 fixture (M40, M44)

A WPF app, a Windows Forms app and a test project for each, on `net11.0-windows`, for loading, running, debugging and testing Windows desktop projects and for WPF XAML editing ([ADR 0071](../../docs/adr/0071-wpf-xaml-language-service.md)). They build on every OS with `EnableWindowsTargeting=true`, which Codalus's build host sets on Linux and macOS; they run on Windows only. And a WinUI 3 app ([ADR 0074](../../docs/adr/0074-maui-on-windows-and-winui.md)), whose packages restore on every OS but which builds only on Windows (WinUI's XAML compiler is a Windows program).

| Project | What it has | Used by |
|---|---|---|
| `WpfApp` | An MVVM app: `App.xaml` merging `Themes/Colors.xaml` and `Themes/Styles.xaml` (brushes, a button style with setters, a control template with `TemplateBinding` and a `TargetName` trigger, style triggers), `MainWindow.xaml` (`d:DataContext` with `d:DesignInstance`, bindings with modes, `UpdateSourceTrigger` and `StringFormat`, `ElementName`, `StaticResource` and `DynamicResource`, a typed `DataTemplate`, attached properties `Grid.Row`, `DockPanel.Dock`, `ToolTipService.ShowDuration` and the app's own `controls:Highlight.IsOn`, a named `TextBox` used in the code-behind, an event handler), `Controls/RatingControl.xaml` (a user control with two dependency properties, `ElementName` and `RelativeSource AncestorType` bindings), `ViewModels/MainViewModel.cs`, `Models/TodoItem.cs` | WPF XAML completion, diagnostics and navigation (the C# host's tests, on every OS); loading and builds; run, debug and the smoke step `windows.desktop` on Windows |
| `WpfApp.Tests` | xUnit v3 (Microsoft.Testing.Platform) tests of the view model | Test runs on Windows; "Windows only" elsewhere |
| `WinFormsApp` | A form (`MainForm.cs`, `.Designer.cs`, `.resx`), a user control (`Controls/CounterControl.cs`, `.Designer.cs`, `.resx`), strongly typed resources (`Properties/Resources.resx` and `Resources.Designer.cs`), and `Counter.cs`, the logic the tests use. For the Windows Forms designer (M41a, [ADR 0073](../../docs/adr/0073-windows-forms-designer.md)): `OrderForm` as Visual Studio for .NET writes it (common controls, a `GroupBox`, a `Panel`, a `TableLayoutPanel` with cells and styles, a `SplitContainer`'s panels, a `ToolTip` in `components`, events, a `NumericUpDown`'s `BeginInit`, an image through `resources.GetObject`, the user control), `AboutForm` as Visual Studio for .NET Framework writes it (`this.`, full type names, a localizable form through `resources.ApplyResources`, its `.resx` and its French `AboutForm.fr.resx`), M41b's `InventoryForm` as Visual Studio for .NET writes it (a menu strip with drop-down items and a separator, a tool strip, a status strip, a context menu strip, a list box's items, a list view's columns and `ListViewItem` locals, tab pages, a data grid view's columns, a `BindingSource` over `InventoryItem` with `DataBindings.Add`, `ToolTip` and `HelpProvider` extender calls, an `ImageList`, an `ErrorProvider`, an image through `resources.GetObject`, its `.resx` with the tray's `TrayLocation`s), and `UnreadableForm`, whose InitializeComponent has a lambda (the SDK's `WFO3010` turned off around it) | Loading, nesting in Solution Explorer, builds; running on Windows; the designer's reader and writer (every OS) and designer host (Windows) |
| `WinFormsApp.Tests` | MSTest (`MSTest.Sdk`) tests of `Counter` | Test runs on Windows |
| `WinUIApp` | A WinUI 3 app (Windows App SDK 1.8, the version MAUI 10.0.110 uses; `net11.0-windows10.0.19041.0`): `App.xaml` merging `XamlControlsResources` and `ms-appx:///Themes/Colors.xaml` (theme dictionaries, styles), `MainWindow.xaml` hosting `MainPage.xaml` (`x:Bind` from the page's `ViewModel` property with modes, a function binding, a named element and `x:Load`; `x:DefaultBindMode`; a data template with `x:DataType`; `ThemeResource` and `StaticResource`; `Grid.Row` and `ToolTipService.ToolTip`; an event handler), `Controls/RatingControl.xaml` (a user control with two dependency properties bound with `x:Bind`), `Package.appxmanifest`. Unpackaged and self-contained by default; `WinUIAppPackaged=true` (a property in the project, or `-p:`) makes it packaged (MSIX), started as `Codalus.Samples.WinUIApp_b1n3b429t8b64!App` | WinUI XAML completion, diagnostics and navigation (the C# host's tests, on every OS); loading off Windows; building, running, debugging and packaged deployment on Windows; the smoke step `maui.windows` |

`WindowsDesktop.slnx` has the WPF and Windows Forms projects; `WpfApp.slnx`, `WinFormsApp.slnx` and `WinUIApp.slnx` have one app each, for the C# host's tests.
