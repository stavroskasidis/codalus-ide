# WCF fixture

For the WCF tests (M42, ADR 0069).

- `CalculatorService`: a CoreWCF 1.9.1 service on ASP.NET Core with two endpoints, `/CalculatorService.svc` (BasicHttpBinding, SOAP 1.1) and `/CalculatorServiceWs.svc` (WSHttpBinding without security, SOAP 1.2 with WS-Addressing), and its metadata on HTTP GET (`/CalculatorService.svc?wsdl`). The contract has simple values (`Add`), a declared fault (`Divide` by zero), a data contract with an enum and a list (`Greet`), and an array back (`FindPeople`). Its launch profile listens on `http://localhost:5280`.
- `CalculatorClient`: a console app with a WCF reference to the service, `Connected Services/CalculatorService/`, generated by `dotnet-svcutil` 8.0.0 from the running service with the classic IDE's default options (`Reference.cs` as the tool wrote it, and the `ConnectedService.json` the classic IDE keeps). The tool added `System.ServiceModel.*` 4.10.* packages; the project pins `System.ServiceModel.Http` and `System.ServiceModel.Primitives` 10.0.652802 instead, so it restores the same everywhere.
- `contracts/CalculatorService.wsdl`: the service's `?singleWsdl`, for adding a reference from a file.

The metadata the service serves (`?wsdl`, `?wsdl=wsdl0`, `?xsd=xsd0`…) and its responses are recorded in `tests/Codalus.Workbench.Tests/TestData/Wcf`.
