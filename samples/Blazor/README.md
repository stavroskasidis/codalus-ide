# Blazor fixture

A Blazor Web App with interactive server rendering, from `dotnet new blazor --interactivity Server --empty`, for the Razor and Blazor tests (M16): `Counter.razor` (an `@code` block, an event handler), `Greeting.razor` (component parameters) used by `Home.razor`, scoped CSS and `_Imports.razor`. `launchBrowser` is off so tests don't open a browser.
